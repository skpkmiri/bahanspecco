1 Tetapan Kebenaran Folder (Sharing Permission)

  • Buka folder Google Drive di atas menggunakan akaun pemilik (AJK Siar Raya).
  • Klik kanan pada nama folder SPECCO → Pilih Share (Kongsi).
  • Di bahagian General Access (Akses Umum), tukar daripada Restricted kepada "Anyone with the link" (Sesiapa sahaja yang mempunyai pautan).
  • Jika menggunakan Google Apps Script Web App (di bawah) supaya peserta muat naik terus melalui borang tanpa membuka Drive: kekalkan Viewer atau Editor pada akaun anda kerana skrip akan berjalan atas kuasa akaun pemilik (Execute as: Me).

2 Integrasi Borang Terus Ke Folder Google Drive (Google Apps Script)

Untuk membolehkan fail yang dimuat naik dalam borang ini terus masuk ke dalam folder Google Drive 1ZXNGbjIrGTIhMb392hevM73Nw1BLjuac secara automatik:

  1. Pergi ke script.google.com dan klik New Project.
  2. Salin kod di bawah dan tampal ke dalam fail Code.gs:
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var folderId = "1ZXNGbjIrGTIhMb392hevM73Nw1BLjuac";
    var folder = DriveApp.getFolderById(folderId);
    
    var decoded = Utilities.base64Decode(data.fileBase64);
    var blob = Utilities.newBlob(decoded, data.mimeType, data.fileName);
    var file = folder.createFile(blob);
    file.setDescription("Sekolah: " + data.schoolName + " | Kategori: " + data.category + " | Guru: " + data.teacherName + " (" + data.teacherPhone + ")");
    
    return ContentService.createTextOutput(JSON.stringify({
      status: "success",
      fileUrl: file.getUrl(),
      fileId: file.getId()
    })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      message: err.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Klik Deploy → New deployment.
  2. Pilih jenis Web app.
  3. Tetapkan Execute as: Me (Akaun Google Cikgu) dan Who has access: Anyone.
  4. Salin Web App URL yang diberikan dan tampalkan ke ruangan Sambungan Google Apps Script Web App di Panel Admin aplikasi ini.
  5. Selain itu, aplikasi ini juga telah disambungkan terus ke pangkalan data Firebase (`bahanspecco`) anda supaya semua penghantaran dan fail tersimpan dengan selamat dan boleh dimuat turun oleh Admin bila-bila masa.
